Подключение к Boosty

Токены хранятся отдельно для каждого пользователя и шифруются.

Выберите способ подключения

Пароль от Boosty в это приложение вводить не нужно.

1. Откройте Boosty.to ↗ и войдите в свой аккаунт.
2. В инструментах разработчика браузера найдите cookie auth домена boosty.to.
3. Скопируйте её JSON-значение (можно в URL-кодировке) сюда.
Официальная авторизация через OAuth в Boosty для этого сервиса не подтверждена. Мы не имитируем форму входа и не запрашиваем пароль Boosty.
