## Принятые проектные правила

1. Один серверный объект поста и один упорядоченный набор текстовых/медийных блоков для живого просмотра и локального HTML.
2. Автономный снимок без CDN-URL с временными токенами; отсутствующие/не выбранные файлы отображаются явно; дата снимка не меняется от проверки на наличие новых постов.
3. Серверные проверки прав для каждого API, медиа, ZIP и поиска; общие архивы доступны только вошедшим пользователям с разрешением. Список получателей не раскрывать.
4. Ограничения API Boosty (комментарии и ответы, HLS/DASH, истёкшие токены) должны отображаться как частичный архив, а не скрываться.
5. Администратор управляет правами, интервалами, квотами, разрешением делиться копиями, обновлениями панели и журналом.
6. Native/systemd и Docker используют одинаковые данные, но безопасно обновляются разными установщиками; обязательны проверка хэшей, резервная копия и откат.
7. Право читать платный пост в Boosty не означает разрешение перепубликовать его третьим лицам.

## Не переносить бездумно

- У WordPress исходники под GPL, поэтому переносим принципы устройства, а не PHP-код.
- У lowfc лицензия CC BY-NC 4.0 с дополнительными ограничениями; использовать UX-идеи, не копировать код напрямую.
- Orbita (MIT) — отдельная платформа со своими платежами: платежи, социальные подписки и её стек серверных сервисов нашему проекту не нужны.
- Кодеки 7-Zip не следует собирать внутрь Go-сервиса без необходимости; для интерактивной библиотеки важнее выборочное чтение и экономное хранение.

## Приоритет разработки

- **P0:** реальные тесты Boosty, загрузка HLS/DASH, квоты, retry/backoff, безопасные автообновления и smoke-тест на VPS.
- **P1:** каталог с поиском/страницами, полноценный рендер DraftJS и комментариев, ревизии/корзина, журнал действий, панель ресурсов.
- **P2:** полнотекстовый поиск, миниатюры, улучшенный просмотр видео, уведомления, управляемые интеграции.

Выполненность отдельных шагов отмечается в [ROADMAP.md](ROADMAP.md), а фактическая работоспособность Boosty должна быть подтверждена отдельными E2E.
