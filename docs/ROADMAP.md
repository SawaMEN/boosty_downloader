# Карта разработки Boosty Downloader Web

Актуально: 10 ноября 2026 года. Это живой технический план; выполненное отражает **реально внесённый код**, а не предполагаемую работоспособность с Boosty.

## Этапы (13)

- [x] **1. Каркас проекта.** Go HTTP-сервис, встроенный интерфейс, GitHub Actions, тесты.
- [x] **2. Начальные серверные установки.** Нативная сборка и systemd, Docker Compose; общие пути хранения и переключение режимов. *Реальный smoke-тест на VPS/Docker ещё нужен.*
- [x] **3. Основы безопасности.** HTTPS, пароль панели, секреты Boosty под AES-GCM, ограничение запросов и проверка URL. *Нужен дальнейший аудит.*
- [x] **4. Первый движок Boosty.** Метаданные поста, список медиа, выбор доступного качества, исходящая загрузка HTTP.
- [x] **5. Начальная выдача в браузер.** Проксирование файлов HTTP-потоком без постоянного сохранения.
- [x] **6. Начальное архивирование поста.** JSON, HTML, изображения, видео, аудио и вложения по выбору; просмотр через панель.
- [x] **7. Начальные комментарии.** Получение комментариев и ответов, маркировка возможного ограничения по данным API.
- [ ] **8. Проверка на реальном Boosty.** Бесплатный и платный посты, видео разного формата, токены, вложения, комментарии, ограничения VPS-IP.
- [ ] **9. Устойчивость архива.** Перепроверка хэшей/размера, повторное получение истёкших CDN-URL, отмена/повтор задач, ограничения диска и скорости.
- [ ] **10. Полная точность поста.** Корректный DraftJS rich-text, вложения комментариев, аватары, изображения вариантов, вложенные списки, исходный порядок и даты.
- [ ] **11. Дополнительные видеоформаты.** HLS/DASH, FFmpeg, внешние плееры с учётом прав доступа.
- [ ] **12. Экспорт и синхронизация.** ZIP, проверки полноты, обновление изменённых постов, фильтры и массовое скачивание, переносимый архив.
- [ ] **13. Выпуск 1.0.** Браузерные e2e, проверка native/docker на Debian/Ubuntu, обновления/откат, проверка автоматического HTTPS по домену и его продления, релизы и эксплуатационная документация.

## Важные ограничения прототипа

- Не проводилось энд-ту-энд скачивание с действующей учётной записью Boosty; серверный API может меняться.
- У API комментариев встречаются ограничения на максимальное количество веток/ответов: приложение обязано отмечать частичный архив.
- В некоторых публикациях видео отдаются как HLS/DASH или через внешний плеер — текущий HTTP-проксирующий режим не превращает такой поток в MP4.
- Извлечение форматированного текста начальное, не гарантирует пиксельную идентичность оригиналу.
- Одна очередь и один worker на инсталляцию; лимиты хранения и архива ZIP ещё не реализованы.
- Установщик предназначен для Linux, systemd (native) и Docker Compose v2 (Docker), с приватного репозитория запускается из локального клона.
- Установки на реальный сервер и тестов Docker в контейнере разработки пока не было.

## Критерии готовности первой стабильной версии

1. `go test -race ./...` и `go vet ./...` проходят.
2. Native и Docker проходят тесты установки на чистой машине, с переключением без потери токенов и архивов.
3. Авторизованное и публичное скачивание работают на проверенных примерах Boosty.
4. Полный пост открывается без сетевых запросов к Boosty, а пропуски явно отражены в манифесте.
5. Неполные комментарии помечаются «частично», без ложного статуса полного архива.
6. Все пользовательские ссылки, медиа, HTML и операции с файлами проходят аудит безопасности.
7. Автоматическое продление сертификатов, восстановление очереди, безопасное обновление и откат проверены.
