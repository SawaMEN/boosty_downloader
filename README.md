# Boosty Downloader Web

Серверный загрузчик и частный архив постов Boosty для Linux VPS. Веб-панель доступна по HTTPS, с отдельной авторизацией администратора. Статус: **первый рабочий прототип**; тестирование с реальным Boosty ещё требуется.

## Возможности первого прототипа

- По ссылке Boosty: проверка поста, список медиа и потоковое скачивание на ПК через VPS.
- Сохранение полной копии поста: HTML + JSON + изображения; опционально видео, аудио, файлы, комментарии с ответами.
- Просмотр сохранённой HTML-страницы через `/library/<автор>/<post-id>/index.html` после закрытия браузера.
- Авторизация через Boosty access token, опционально refresh token + device ID; хранение AES-GCM с ключом вне данных медиатеки.
- Фоновая очередь, восстанавливаемая после рестарта, частичная HTTP Range-докачка.
- Нативная установка (Go + systemd) **или** Docker Compose с одними и теми же каталогами данных.
- Запуск по IP или домену, настройка порта, HTTPS с самоподписанным или готовым PEM-сертификатом.

## Установка (как в Firewall-UI)

> **Внимание:** репозиторий пока приватный. Команда `curl https://raw.githubusercontent.com/.../install.sh | bash` без авторизации GitHub **не работает**. Сначала клонируйте репозиторий через `gh auth login` / персональный токен / SSH-ключ.

```bash
gh repo clone SawaMEN/boosty_downloader
cd boosty_downloader
sudo bash install.sh
```

В меню выберите `1) Native` или `2) Docker`, затем IP/домен и сертификат. Для локального доступа можно выбрать `127.0.0.1` и использовать SSH-туннель. По умолчанию порт **8443**.

**Зависимости первой установки:** Linux; `openssl`, `useradd`; для native — systemd и Go 1.23+ (позже будет установка готового релизного бинарника), для Docker — Docker Engine и Compose v2 (Go на VPS не требуется). При переключении режимов повторно запустите `sudo bash install.sh`, выбрав другой вариант.

Без вопросов (для автоматизации, из клона):

```bash
sudo env BD_PUBLIC_HOST=203.0.113.10 BD_PORT=8443 BD_TLS_MODE=selfsigned \
  BD_ADMIN_USER=admin BD_ADMIN_PASSWORD='ChangeMe12345678' bash install.sh --mode native
```

Адрес `203.0.113.10` — пример из документационного диапазона, замените своим реальным IP.

## Управление

```bash
sudo bdy                # Меню управления
sudo bdy status
sudo bdy logs
sudo bdy start
sudo bdy stop
sudo bdy restart
sudo bdy update        # Инструкция по обновлению из нового клона
sudo bdy uninstall     # Удалить службу и приложение, сохранить архив
sudo bdy uninstall --purge  # Также удалить настройки, токены и все архивы (подтверждение)
```

Native и Docker используют:

| Назначение | Путь на хосте |
| --- | --- |
| Конфигурация, пароль, ключ | `/etc/boosty-downloader/environment` |
| Сертификаты | `/etc/boosty-downloader/tls/` |
| Архивы/токены/очередь | `/var/lib/boosty-downloader/` |
| Нативный бинарник | `/usr/local/boosty-downloader/boosty-downloader` |
| Docker-сборка | `/opt/boosty-downloader/` |

### HTTPS

Панель требует HTTPS, включая IP-доступ. Самоподписанный сертификат вызовет предупреждение браузера; для общедоступного домена рекомендуется получить доверенный сертификат, передав его PEM-файлы при установке. Сертификаты в этом прототипе **не продлеваются автоматически**. Не открывайте административную панель в публичном доступе без надёжного пароля и доверенного сертификата.

Порт на внешнем файрволле хостинга необходимо разрешить вручную. Установщик **не меняет** правила UFW/nftables/iptables и чужие Docker-ресурсы.

## Ограничения и безопасность

- Закрытый контент доступен только пользователям с действующей подпиской/правами доступа. Инструмент не обходит DRM и платные ограничения.
- Видео HLS/DASH, внешние плееры, сложный формат DraftJS, все ответы при API-лимитах, экспорт ZIP и удаление/повтор задач — пункты следующего этапа.
- Комментарии могут выдаваться Boosty частично; манифест включает соответствующий статус.
- Не размещайте зашифрованные токены отдельно от ключа на публичном ресурсе; файлы `/etc/boosty-downloader` защищены режимами доступа ОС.
- Рекомендуется делать резервную копию `/etc/boosty-downloader` вместе с `/var/lib/boosty-downloader` (иначе токены не расшифруются).
